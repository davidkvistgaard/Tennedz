# Rider marketplace implementation status

The first version supports fixed-price listings in coins. A signed-in manager can search active listings by name, category, three-letter nationality, age, price and one selected skill; sort by price or the selected skill; list an owned rider; cancel their own listing; and buy another team's rider. The market page deliberately uses initials rather than showing a seller in the buyer's current club kit.

The additive migration `20261029153000_rider_marketplace.sql` stores listings and completed sale receipts, requires one current owner per rider, and restricts the table and four RPC functions to the server's service role. The server checks the signed-in user's team and same-origin POST; `MARKETPLACE_ALLOW_WRITES=true` independently guards market writes while the race recovery switch remains closed. The buy function takes the same advisory transaction lock as the race cycle, rechecks listing state and ownership, refuses riders in unfinished entries or saved lineups, charges the buyer, credits the seller and moves the existing rider link in one transaction. The rider ID, saved appearance and historical race rows remain the same. A sold listing cannot be bought twice.

Local verification on 29 October 2026: two input-validation tests passed; a pinned PGlite PostgreSQL test executed the migration and checked listing, search, purchase, cancellation, unique ownership, insufficient funds, self-purchase, race/lineup refusal and table access controls. ESLint and an isolated 48-page Next.js build passed. One authenticated browser fixture test passed for search, sale, cancellation, purchase and 390-pixel width; it does not use Supabase. Screenshots were inspected.

**Not released:** No migration was applied to a Supabase project and no real two-team transaction was run through PostgREST. Before enabling market writes, apply and test the migration in an isolated project with real authenticated teams, inspect advisories and database permissions, test concurrent purchase and race entry, and verify browser reload, balances, ownership and history. The production game-write switch is currently closed. Do not deploy this feature to tennedz.eu while the owner is waiting for the Motor Lab race feature.
