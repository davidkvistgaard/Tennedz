# Pelotonia logo v0.1

The owner-supplied image is the visual reference. Production artwork is original flat SVG: a cream `P` whose stem becomes a green road curving into the bowl. The lettering contains only `PELOTONIA`.

| Use | Asset |
| --- | --- |
| Icon only, forest background | `/brand/pelotonia-icon.svg` |
| Primary horizontal lockup | `/brand/pelotonia-horizontal.svg` |
| Primary stacked lockup | `/brand/pelotonia-stacked.svg` |
| One-colour cream on dark | `/brand/pelotonia-monochrome-light.svg` |
| One-colour forest on light | `/brand/pelotonia-monochrome-dark.svg` |
| Simplified app icon and favicon | `app/icon.svg` |

Palette: forest `#0E2D24`, Pelotonia green `#4FB28A`, cream `#F6F4EC`, sage `#5E806E`, ink `#10191A`. The five tokens live in `app/globals.css`; the shared studio's primary forest, paper and ink roles use them. The P silhouette and road remain readable at favicon size; the dashed road centreline appears only in larger full-colour lockups. Wordmarks use SVG text and therefore remain vectors; their Arial/Helvetica font stack should be checked on every export surface. No generated bitmap is served as the logo.

The horizontal lockup appears in the public and signed-in navigation; the dark monochrome lockup appears on the light sign-in/sign-up panels and in the public footer. The light monochrome asset is available for dark surfaces. Existing page text and game UI are outside the logo artwork.
