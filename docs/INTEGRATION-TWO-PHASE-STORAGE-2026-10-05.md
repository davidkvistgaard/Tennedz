# Isolated two-phase race storage probe

`20261005061416_opt_in_two_phase_race_storage.sql` adds optional registration and tactics deadlines to scheduled one-day events. For opted-in events, the existing `deadline` must equal registration close, followed by tactics close and race start. Old events have both new values null and retain their current path.

The private reveal parent records event, season, gender and points-policy version. Its child rows record each entered team, earned points at registration lock, division and seed rank. The event/team foreign key prevents a reveal row for an unentered team; unique keys prevent duplicate teams and seed ranks. Only the server role has direct access. The migration also blocks any result commit for an opted-in event until the reveal and final tactics transaction are implemented. This is deliberate fail-closed scaffolding, not an active two-phase feature.

Applied **only** to isolated project `nxhvaoonnvmvohqaxfdx`. `tests/support/two-phase-storage-probe.sql` passed there: invalid deadline order failed the named constraint, an opted-in commit failed with the expected phase error, and a legacy commit remained permitted. The probe rolls back its temporary event updates and inserts. Follow-up queries found zero opted-in events and zero reveal rows, with no anonymous or authenticated read grant. Security advisors reported the expected private-table RLS/no-policy notices; performance advisors found no missing index for the new foreign keys. The new team index is naturally still unused.

Remaining before an end-to-end two-phase test: decide provisional placement for zero-point teams; serialize reveal with manual joins, autopilot and race commits; resolve or report queued autopilot work; persist the frozen point rows and assignments; allow entered managers to edit tactics until a separate lock; save final race input; expose only opponents' public details; and verify all 45 entrants across three recorded divisions, points and idempotent reruns. None of this storage migration has been applied to production.
