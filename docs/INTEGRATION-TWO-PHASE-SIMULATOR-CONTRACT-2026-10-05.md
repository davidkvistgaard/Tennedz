# Locked two-phase input reaches the JavaScript simulator

The rollback-only `tests/support/two-phase-simulator-contract-probe.sql` temporarily converted an existing two-team fixture to an opted-in race in the isolated Supabase project. It completed the automatic-entry job, committed the point-based division reveal, saved valid orders, locked tactics, selected the **saved** `recovery_race_snapshot`, and rolled back. The returned private JSON was passed to the local `tests/support/verify-two-phase-simulator-contract.mjs` helper. The actual simulator produced one division with two teams, 16 riders and a 16-rider recorded replay. It reproduced the saved assignments and deterministic output. A follow-up query confirmed the source event stayed legacy and the probe left no reveal, tactics lock or autopilot job.

The snapshot contains private lineups and orders. Keep temporary copies in ignored local test output and delete them after the check. This test verifies the database-to-simulator input contract and local recorded output; it does **not** commit that output to the database or exercise 45 independently authenticated managers. Those remain part of the playable milestone. Production data and deployments were untouched.
