# Motor Lab — first visible engine milestone

This slice adds `/team/motor-lab` for signed-in managers and a read-only `POST /api/motor-lab`. It is a fictional, isolated demonstration, not the official race viewer or an alternate live race runner. The current race engine, results, Supabase schema/data, scheduled jobs and points are unchanged.

The manager chooses one of four simple Amber plans, one of two fictional 160 km routes, and a bounded scenario number. The server builds the same four synthetic eight-rider squads, runs `v2-prototype-78`, validates the complete in-memory recording and returns a presentation of each kilometre: road groups, attack and chase reasons, conditions, energy and notable movements. The browser can scrub, play at three speeds, jump between moments and break episodes, and compare the first changed road moment in two runs of the same scenario. Changing an order requires a new calculation. The experimental provisional result is labelled as such. No engine tuning table or hidden coefficient is bundled into the browser.

The API uses existing authenticated team ownership and same-origin checks, a bounded input and supplemental per-process rate limit. It never reads the manager's riders or writes any database row. Precommitted orders now cover chase contribution, bunch attack posture, a timed change to each after 120 km, break cooperation, one-off attacks from a break, captain support, helper freedom, road-captain leadership and effort. The fixtures remain intentionally small: four fictional teams and generic male riders on fixed Coast and Ridge roads. They cannot establish realistic balance, category parity, stage racing or suitability for official events. Real-roster orders, a full official viewer and test-race persistence remain later milestones.

Verification through 1 October 2026: 256 unit tests, repository ESLint, clean production build and authenticated 390/1440 px browser journeys. Browser checks include anonymous rejection, foreign-Origin rejection, plan and order selection, server-calculated replay, scrubbing, moment navigation and same-seed comparisons. Paired scenario audits in `MOTOR-LAB-BALANCE-AUDIT.md` expose an excessive advantage for attacks held until the final 40 km; a contextual note warns the tester in that case. The engine is still experimental. World Baseline 1.6.2 remains in the same release candidate. No migration is needed for this slice.
